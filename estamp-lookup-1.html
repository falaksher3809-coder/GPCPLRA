Punjab Citizen Portal — unauthenticated proxy endpoints
client-side only, no server, no storage
Before you query anyone: These endpoints return real personal and financial data for any CNIC you supply — there is no login or authorization check on the API itself. Only look up CNICs you are actually authorised to check (your own, or as part of your official duties). Nothing here should be used to look up people out of curiosity.
Dashes are stripped automatically. History of your last few searches is kept only in this tab's memory — nothing is saved to disk.

Stamp detail

Requests go directly from your browser to es.punjab-zameen.gov.pk. This page deliberately sends "simple" requests (no custom headers, no JSON body) because the server rejects the OPTIONS preflight browsers send for anything fancier — so adding headers back in will break it again. If you still see a CORS error in the console, the server isn't allow-listing this page's origin at all, which is a server-side policy and not fixable from here; options are hosting from an origin it already allows, a browser extension that disables CORS for testing, or a local proxy you control. Full request/response detail is always logged to the console.
